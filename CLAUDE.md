# Reglas de trabajo (ahorro de tokens)
1. Modelo grande solo para feature, architecture, debug-hard. El resto va por `harness/run.py` (small/medium).
2. Tareas repetitivas: usar `scripts/*.sh`, nunca hacerlas a mano.
3. Sin capturas de pantalla ni logs completos. Solo hitos en MILESTONES.md.
4. No releer archivos ya vistos; pedir solo el fragmento necesario.
5. Respuestas cortas: diff o codigo, sin explicar lo obvio.
6. Cada mejora termina con un enlace al preview interactivo.
